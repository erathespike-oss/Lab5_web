# Lab 5 — Event Registration

Консольная программа на Java для регистрации на мероприятия.
Автор: Kamal Meiirbek. Группа: IT3 2502DS.
Данные хранятся в памяти и исчезают после выхода.

## Запуск

Проверено с JDK 21. Используй установленный JDK 21 для Gradle и IntelliJ IDEA.
Код компилируется с целевой версией Java 17.
Отдельно устанавливать Gradle не нужно: в проекте есть Gradle Wrapper.
При первом запуске он скачает Gradle, поэтому нужен интернет.

В терминале Linux из папки проекта:

```bash
./gradlew --console=plain run
```

В Windows: `gradlew.bat --console=plain run`.
Сборка: `./gradlew build`.

В IntelliJ IDEA открой проект, дождись загрузки Gradle, выбери Project SDK 21,
затем открой `src/main/java/registration/Main.java` и нажми зелёную кнопку
рядом с `public static void main(String[] args)`.
Gradle JVM в настройках IDEA тоже должен быть JDK 21.

Без Gradle (если пока нет интернета):

```bash
mkdir -p build/classes/manual
javac -encoding UTF-8 --release 17 -d build/classes/manual src/main/java/registration/*.java
java -cp build/classes/manual registration.Main
```

## Три класса

- `Registration` — одна заявка. Пять закрытых полей, конструктор, getters и `toString()`.
  Конструктор проверяет данные и обрезает пробелы по краям имени, email и группы.
- `RegistrationManager` — хранит `ArrayList<Registration>`, добавляет, ищет,
  удаляет и выводит заявки. Счётчик `nextId` начинается с 1 и не уменьшается после удаления.
- `Main` — читает ввод через `Scanner`, показывает меню и вызывает менеджер.
  Все строки читаются через `nextLine()`, поэтому имя может содержать пробелы.

## Меню

1. Добавить заявку: имя, email, группа, номер мероприятия (1–3).
2. Показать все заявки.
3. Найти по ID.
4. Удалить по ID.
5. Показать заявки выбранного мероприятия.
0. Выйти.

При ошибке программа объясняет причину и возвращает меню. Чтобы повторить
добавление, выбери 1 снова. Частично заполненная или неверная заявка не сохраняется.
Email проверяется по упрощённому правилу задания: есть @ и текст с обеих сторон.

## Что объяснить на защите

Класс — описание, объект — конкретная заявка, созданная через `new`.
`private` запрещает прямое изменение полей из других классов; getters читают их.
Конструктор проверяет и задаёт начальные значения.
`ArrayList` позволяет хранить изменяющееся количество заявок.
Поиск перебирает список и сравнивает ID через `getId()`.
Удаление идёт по индексу, поэтому список изменяется безопасно.
`try/catch` обрабатывает неверный ввод чисел и ошибки проверки данных.

## Проверка перед сдачей

Пустой список; две корректные заявки; короткое/пустое имя; email без @;
пустая группа; буквы вместо пункта меню, ID и номера события;
неизвестный пункт меню; событие вне 1–3; поиск существующего и отсутствующего ID;
фильтр с результатом и без; удаление и добавление с новым ID; выход через 0.

Для демонстрации: добавь заявку, вызови ошибку, найди заявку по ID и удали её.
Сборочные файлы и настройки IDE исключены через `.gitignore`.
